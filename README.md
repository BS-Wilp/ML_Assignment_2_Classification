# Adult Income Prediction

BITS WILP - Machine Learning Assignment 2

## Project Description
This project predicts adult income categories using machine learning classification algorithms on the Adult Income dataset.

## Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Gaussian Naive Bayes
- Support Vector Machine (SVM)

## Streamlit Application
Users can select a model, upload CSV data,
generate predictions, and download results.

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run:
   streamlit run app.py
